# - Site - F3F Gestão energética — Plataforma de Gestão Integrada de Projetos de Energia 

Plataforma web institucional desenvolvida para a **F3F Gestão**, especializada na coordenação unificada de projetos elétricos, solares, Mercado Livre de Energia e mobilidade elétrica (parceria WEG / WEMOB).

## 🛠️ Tecnologias Utilizadas
* **HTML5 / CSS3** (Design Responsivo com Grid/Flexbox e variáveis customizadas).
* **JavaScript Vanilla** (Manipulação de estados e visualização de páginas internas em lote/SPA).
* **Google Fonts** (IBM Plex Sans, Space Grotesk, IBM Plex Mono).

## 🚀 Como Executar Localmente
1. Acesse o diretório do projeto (ex: `C:/_a/site/`).
2. Dê um duplo clique no arquivo **`dev.bat`** ou abra o arquivo **`index.html`** diretamente no seu navegador.

## 📂 Estrutura de Arquivos
* `index.html` — Código fonte principal com o site completo e a página de mobilidade integrada.
* `dev.bat` — Script utilitário de automação para Windows.
* `README.md` — Documentação do projeto.
